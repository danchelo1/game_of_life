# Game of Life

Реализация классической клеточной автоматической игры «Жизнь» Джона Конвея на языке C с выводом в терминал через библиотеку **ncurses**.

## О проекте

Игра происходит на поле фиксированного размера **80×25** клеток. Каждая клетка может быть живой или мёртвой. На каждом шаге состояние всех клеток пересчитывается одновременно по правилам Конвея. Поле **тороидальное** — противоположные края замкнуты друг на друга (клетки у левого края соседствуют с клетками у правого, верхние — с нижними).

### Правила

Для каждой клетки считается число живых соседей (из 8 окружающих):

- **Живая** клетка выживает, если у неё **2 или 3** живых соседа, иначе умирает (от одиночества или перенаселения).
- **Мёртвая** клетка оживает, если у неё ровно **3** живых соседа.

## Сборка

Требуется компилятор C и установленная библиотека `ncurses`.

```bash
gcc game_of_life.c -o game_of_life -lncurses
```

На macOS библиотека ncurses обычно уже присутствует. В Linux при необходимости установите пакет разработки:

```bash
# Debian/Ubuntu
sudo apt install libncurses-dev
```

## Запуск

Начальное состояние поля подаётся на **стандартный ввод**, поэтому файл с шаблоном перенаправляется в программу:

```bash
./game_of_life < pattern.txt
```

В комплекте идут готовые стартовые конфигурации: `pattern.txt`, `pattern1.txt`, `pattern2.txt`, `pattern3.txt`, `pattern4.txt`.

## Управление

| Клавиша      | Действие                          |
|--------------|-----------------------------------|
| `a` / `A`    | ускорить (уменьшить задержку)      |
| `z` / `Z`    | замедлить (увеличить задержку)     |
| `Пробел`     | выйти из игры                      |

Задержка между кадрами изменяется шагами по 10 000 мкс в диапазоне от 10 000 до 500 000 мкс (стартовое значение — 100 000 мкс).

## Формат входного файла

Файл должен содержать **25 строк по 80 символов**, описывающих начальное поле:

- `1` или `*` — живая клетка;
- `0` — мёртвая клетка.

Любые другие символы (например, переводы строк) игнорируются при чтении. Если во входных данных недостаточно значений для заполнения всего поля, программа завершится с ошибкой.

Пример фрагмента (глайдер):

```
010
001
111
```

## Как это работает

После чтения начального поля программа переключает стандартный ввод обратно на терминал (`/dev/tty`), чтобы читать нажатия клавиш во время работы, и запускает игровой цикл:

1. отрисовка текущего поля (живые клетки — символ `#`);
2. вычисление следующего поколения;
3. обработка ввода пользователя;
4. пауза на заданную задержку.
